# Keyboard shortcuts

`?` shows the shortcuts in effect, your changes included. Two keys in a row (`g a`) are pressed one after the other; capitals need Shift.

Shortcuts do nothing while you type in a field (except `Esc`), in a dialog or menu, or with Ctrl, Alt, or ⌘ held. "Single-key keyboard shortcuts" in Settings > Preferences turns them off.

## Defaults

Navigation:

| Keys | Action |
|---|---|
| `j` / `k` | Next / previous feed |
| `n`, `↓` / `p`, `↑` | Next / previous article |
| `N` / `P` | Scroll the article down / up |
| `Esc`, `a q` | Close the article |
| `/` | Search |
| `x` | Collapse or expand the category |
| `c e` / `c c` | Expand / collapse all categories |

Article:

| Keys | Action |
|---|---|
| `s` | Star or unstar |
| `S` | Publish or unpublish |
| `u` | Mark read or unread |
| `o` | Open the original |
| `a n` | Add or edit the note |
| `a l` | Choose labels |
| `T` | Edit tags |

Feeds:

| Keys | Action |
|---|---|
| `f r` | Update the feed |
| `f a` | Show or hide feeds without unread articles |
| `f s` | Subscribe to a feed |
| `f e` | Edit the feed |
| `f q` | Mark the feed as read |
| `f x` | Reverse the order |
| `f C` | Switch between three panes and the combined layout |
| `Q` | Mark everything as read |

Go to:

| Keys | Action |
|---|---|
| `g a` | All articles |
| `g f` | Fresh |
| `g s` | Starred |
| `g p` | Published |
| `g r` | Recently read |
| `g t` | Tags |
| `g P` | Settings |
| `?` | This help |

## Change them

Settings > Shortcuts lists every action. "+" records up to four keys or two-key sequences for an action, which replace its defaults; keys already used elsewhere move to it, and a sequence cannot start with another's keys. Space, Tab, and keys pressed with Ctrl, Alt, or ⌘ cannot be used. Each action can be reset, or all with "Reset all shortcuts".

Your shortcuts are saved with your account, so they follow you to every device.
